# Plans

One file per multi-file task: `YYYY-MM-DD-<slug>.md`.

## Template

```md
# <Task>

Status: draft | approved | done
Owner lane:
Scope file: .scope

## Intent
## Contract impact
## Steps
1.
## Acceptance
- [ ]
## Verification
## Risks
```

## Rules

- Write the plan before the first edit.
- Link the plan from the pull request.
- Keep the file after merge. It records what was intended, not just what happened.
- If the plan changes mid-task, edit it and state why.
- A plan that contradicts a Prevention rule in `../solutions/` must say why.
